## 2. Dataset Overview and Theoretical Acquisition Geometry

The **Database for Mastology Research — Infrared (DMR-IR)** is a publicly hosted Hugging Face dataset (`SemilleroCV/DMR-IR`) containing multi-view breast thermography acquisitions in 16-bit TIFF format. The raw data represents thermal emissions measured in the infrared spectrum, which correspond to temperature distributions across the skin surface. We can define a thermal image as an intensity function $I_{\theta_k}: \Omega \to \mathbb{R}$, where $\Omega \subset \mathbb{Z}^2$ is the image domain and $\theta_k$ is the camera's azimuthal angle.

Each patient record includes up to five canonical thermal views captured at standardised angular positions. This geometry is formally defined by the view set $\mathcal{V} = \{ \theta_0, \theta_1, \theta_2, \theta_3, \theta_4 \}$:

| View Index $k$ | Angle $\theta_k$ (°) | Description |
|:---:|:---:|---|
| 0 | $0$ | Frontal |
| 1 | $+45$ | Right oblique |
| 2 | $-45$ | Left oblique |
| 3 | $+90$ | Right lateral |
| 4 | $-90$ | Left lateral |

### 2.1 The Visual Hull Formulation

The selection of these five canonical angles is not arbitrary. From a theoretical reconstruction standpoint, recovering a 3D surface from 2D silhouettes relies on the concept of the **visual hull**. The visual hull $\mathcal{H}$ of an object is defined as the maximum bounding volume consistent with a set of silhouettes, computed as the intersection of viewing cones:

$$ \mathcal{H} = \bigcap_{k=0}^{4} \mathcal{C}(S_k, \mathbf{c}_k) $$

where $S_k \subset \Omega$ is the binary silhouette extracted from the $k$-th view, $\mathbf{c}_k \in \mathbb{R}^3$ is the camera's optical centre, and $\mathcal{C}(S_k, \mathbf{c}_k)$ represents the infinite viewing cone generated by back-projecting the silhouette $S_k$ into 3D space. The angles $0^\circ, \pm 45^\circ$, and $\pm 90^\circ$ provide an optimal configuration that bounds the convex envelope of the breast anatomy from all anterior directions, capturing maximum boundary information while keeping clinical acquisition times minimal.

## 3. Methodology

### 3.1 Streaming Metadata Inspection

Because the full dataset exceeds 5 GB, the notebook employs the Hugging Face `datasets` library with **streaming mode** enabled:

```python
ds = load_dataset("SemilleroCV/DMR-IR", split="train", streaming=True)
```

Streaming avoids downloading the entire corpus; only the dataset schema (features, column types, label names) is fetched. This is a lightweight and efficient approach to metadata inspection.

### 3.2 Categorical Label Extraction

The notebook iterates over the dataset's `features` dictionary and identifies all columns whose type is `ClassLabel`. In information theory and machine learning, a categorical feature can be viewed as a mapping from a discrete integer space to a nominal set. Hugging Face's `ClassLabel` exposes this as a bijective mapping:

$$ f : \{0, 1, \dots, N-1\} \to \mathcal{S} $$

where $\mathcal{S}$ is a finite set of human-readable string labels (e.g., $\mathcal{S} = \{\text{'benign'}, \text{'malignant'}\}$).

Extracting this mapping is essential to:

1. Confirm the presence of the **diagnosis** label for class stratification.
2. Identify any **view-angle** or **laterality** labels required to parse the multi-view acquisition protocol.
3. Ensure the sample space $\mathcal{S}$ is well-behaved (i.e., no unexpected classes exist that could skew the class prior probabilities during modelling).

## 4. Significance for Downstream Stages

The statistical and categorical information extracted here directly feeds into:

- **Stage 2 (U-Net Segmentation):** The dataset is split 78 % / 22 % train/test, preserving the underlying class marginal distribution $P(y)$ via stratified sampling.
- **Stage 3 (3D Reconstruction):** Patient folders are grouped by diagnosis, and only patients fulfilling the necessary geometric condition (a complete set of $N_{\text{views}}=5$) are admitted to the reconstruction pipeline to ensure the visual hull $\mathcal{H}$ is tightly bounded.
- **Stage 4 (PINN Bioheat):** The benign/malignant label serves as the ground-truth clinical variable. The inverse bioheat problem seeks to estimate thermal conductivity and perfusion parameters, which are hypothesized to correlate strongly with these diagnosis labels.
